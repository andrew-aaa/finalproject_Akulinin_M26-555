# ValutaTrade Hub

Учебный проект — платформа для отслеживания и симуляции торговли валютами.

## Возможности

Программа поддерживает следующие команды:

* регистрация нового пользователя;
* вход пользователя в систему;
* просмотр текущего портфеля;
* покупка валюты;
* продажа валюты;
* получение курса одной валюты к другой;
* выход из программы;
* просмотр списка доступных команд.

Все данные пользователей, портфелей и курсов сохраняются в формате JSON.

## Технологии

Проект написан на Python 3.12+.

Используются:

* Python;
* `json` для хранения данных;
* `hashlib` для хеширования паролей;
* `datetime` для работы с датами и временем;
* `shlex` для разбора командной строки;
* `prettytable` для вывода портфеля в табличном виде;
* `uv` для управления проектом и зависимостями.


## Доступные команды

### Регистрация

```text
register --username <имя> --password <пароль>
```

Пример:

```text
register --username test --password 1234
```

Пароль должен содержать не менее 4 символов.

После регистрации пользователю создаётся начальный портфель с валютой USD.
Валюту необходимо вручную добавть в portfolios.json в поле "balance".

### Вход

```text
login --username <имя> --password <пароль>
```

Пример:

```text
login --username test --password 1234
```

После успешного входа появляется сообщение:

```text
Вы вошли как 'test'
```

Операции с портфелем доступны только авторизованному пользователю.

### Просмотр портфеля

```text
show-portfolio
```

Команда показывает:

* валюты пользователя;
* количество каждой валюты;
* стоимость валют в базовой валюте;
* общую стоимость портфеля.

По умолчанию базовой валютой является USD.

Пример:

```text
Портфель пользователя 'test' (база: USD):
- USD: 994.6000 → 994.60 USD
- EUR: 5.0000 → 5.40 USD
---------------------------------
ИТОГО: 1,000.00 USD
```

### Покупка валюты

```text
buy --currency <валюта> --amount <количество>
```

Пример:

```text
buy --currency EUR --amount 10
```

При покупке с USD-кошелька списывается необходимая сумма, а купленная валюта добавляется в портфель.

Пример результата:

```text
Покупка выполнена: 10.0000 EUR по курсу 1.08 USD/EUR
Стоимость покупки: 10.80 USD
```

### Продажа валюты

```text
sell --currency <валюта> --amount <количество>
```

Пример:

```text
sell --currency EUR --amount 5
```

При продаже указанное количество валюты списывается с соответствующего кошелька, а полученная сумма в USD зачисляется на USD-кошелёк.

Пример результата:

```text
Продажа выполнена: 5.0000 EUR по курсу 1.08 USD/EUR
Выручка: 5.40 USD
```

### Получение курса

```text
get-rate --from <валюта> --to <валюта>
```

Пример:

```text
get-rate --from USD --to EUR
```

Результат:

```text
Курс USD→EUR: 0.92592593
Обратный курс EUR→USD: 1.08000000
```

Курсы сохраняются в `data/rates.json`.

Для получения курса используется кэш. Если сохранённый курс был обновлён менее 5 минут назад, он используется повторно. В проекте также реализовано кэширование результата функции в памяти с помощью замыкания.

### Список команд

```text
help
```

Показывает список доступных команд.

### Выход

```text
exit
```

Завершает работу программы.

## Работа с данными

Приложение использует JSON-файлы для хранения данных.

### `users.json`

Содержит информацию о зарегистрированных пользователях. Пароли не хранятся в открытом виде: используется SHA-256 и индивидуальная соль.

### `portfolios.json`

Содержит информацию о валютных кошельках пользователей и их балансах.

### `rates.json`

Содержит сохранённые курсы валют и время их последнего обновления.

Данные сохраняются между запусками приложения, поэтому после повторного запуска ранее созданный пользователь и его портфель остаются доступными.

## Валюты

В проекте используются фиксированные курсы валют, заданные в коде приложения.

Поддерживаются:

* USD;
* EUR;
* GBP;
* JPY;
* RUB;
* BTC;
* ETH.

USD используется как базовая валюта для операций покупки и продажи.

## Проверка данных

В приложении предусмотрены проверки пользовательского ввода.

Проверяется:

* непустое имя пользователя;
* длина пароля не менее 4 символов;
* положительный идентификатор пользователя;
* корректный формат даты регистрации;
* непустой код валюты;
* использование кода валюты в верхнем регистре;
* положительная сумма операции;
* достаточность средств для покупки;
* достаточность валюты для продажи;
* наличие пользователя при входе;
* правильность пароля.

Ошибки обрабатываются через исключения и выводятся пользователю в консоль.

## Безопасность паролей

Пароль пользователя не сохраняется в исходном виде.

При регистрации:

1. создаётся соль;
2. пароль объединяется с солью;
3. результат хешируется с помощью SHA-256;
4. в файл сохраняются хеш пароля и соль.

При входе введённый пароль хешируется с сохранённой солью и сравнивается с сохранённым хешем.

## Декораторы и кэширование

В проекте используются декораторы для дополнительной функциональности.

Декоратор `log_action` выводит в консоль информацию о вызове функции.

Пример:

```text
[LOG] Вызов функции: get_rate
[LOG] Функция get_rate выполнена
```

Также используется декоратор с замыканием `cache_with_ttl`, который хранит результаты вызовов функций в памяти в течение заданного времени.
